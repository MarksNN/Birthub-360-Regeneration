MAPEAMENTO DE ENTIDADES E DADOS PESSOAIS (Prisma Schema)
----------------------------------------------------------

Tabela: User
- Dados pessoais: email, name
- Sensibilidade: ALTA (email identifica)
- Finalidade: Autenticação, RBAC, auditoria
- Base legal: Execução de contrato
- Retenção: Enquanto usuário ativo + obrigação legal (pode ser anonimizado após período)

Tabela: Company
- Dados pessoais: name, tradeName, cnpj, phone
- Sensibilidade: MÉDIA (dados empresariais)
- Finalidade: CRM, gestão de clientes
- Base legal: Execução de contrato, legítimo interesse
- Retenção: Enquanto relação comercial ativa

Tabela: Contact
- Dados pessoais: name, email, phone, roleTitle
- Sensibilidade: ALTA (email, telefone de pessoa física)
- Finalidade: CRM, comunicação
- Base legal: Execução de contrato, consentimento (quando marketing)
- Retenção: Enquanto necessário para CRM

Tabela: Lead
- Dados pessoais: title (pode conter nome), notes (pode conter PII)
- Sensibilidade: MÉDIA
- Finalidade: Prospecção comercial
- Base legal: Legítimo interesse, consentimento
- Retenção: Período comercial definido (ex: 2 anos sem conversão)

Tabela: Activity
- Dados pessoais: description (pode conter PII)
- Sensibilidade: BAIXA (desde que minimizada)
- Finalidade: Gestão de tarefas
- Base legal: Execução de contrato
- Retenção: Curto prazo (ex: 1 ano)

Tabela: AuditLog
- Dados pessoais: userId, diff (pode conter PII)
- Sensibilidade: ALTA (se diff não sanitizado)
- Finalidade: Auditoria, compliance
- Base legal: Obrigação legal, legítimo interesse
- Retenção: Longo prazo (ex: 5-7 anos)

Tabela: SupervisorExecution
- Dados pessoais: userPrompt (pode conter PII), resultSummary
- Sensibilidade: ALTA (prompts podem conter dados sensíveis)
- Finalidade: Orquestração de IA
- Base legal: Execução de contrato
- Retenção: Curto prazo (ex: 30 dias) ou anonimização

Tabela: IntegrationConnection
- Dados pessoais: config (pode conter credenciais), credentialRef
- Sensibilidade: CRÍTICA (credenciais)
- Finalidade: Integrações
- Base legal: Execução de contrato
- Retenção: Enquanto ativa + backup

Tabela: WebhookInboxEvent / IntegrationOutboxEvent
- Dados pessoais: payload (pode conter PII)
- Sensibilidade: ALTA
- Finalidade: Sincronização
- Base legal: Execução de contrato
- Retenção: Curto prazo (ex: 7-30 dias)

4. SupervisorExecution.userPrompt pode conter dados sensíveis sem máscara
5. NÃO há mecanismo de expurgo/anonimização automático
6. NÃO há legal hold implementado
7. Logs podem conter PII (verificar código)
