03.2 — REGISTROS DE DECISÃO ARQUITETURAL (ADRs MESTRES)

STATUS: OFICIAL & HOMOLOGADO • Versão: 1.0.0 • Lote C

ADRTítulo & DecisãoContexto & JustificativaConsequências & Status
ADR-001 Monorepo Estruturado Modular (Backend Express + Frontend Vite) Necessidade de desacoplar contratos de API e interfaces sem a complexidade de microserviços prematuros. APROVADO / IMPL Build rápido, tipagem estrita compartilhável.
ADR-002 Isolamento Multi-tenant via `organizationId` Rigoroso em Banco Único Custo-eficiência para estágio inicial combinado com integridade referencial forte via chaves estrangeiras. APROVADO / IMPL Toda query Prisma exige filtro por `organizationId`.
ADR-003 PostgreSQL Isolado em Docker na Porta 5433 Evitar colisões catastróficas com bancos e instâncias do repositório antigo na porta 5432. APROVADO / IMPL Preserva ambiente legado intacto.
ADR-004 Supervisor como Facade Único com Despacho Real de Ferramentas Evitar chatbots fictícios; toda chamada avalia intenção, autorização RBAC e despacha ferramentas auditáveis. APROVADO / IMPL Transparência total sobre agentes reais vs catalogados.
ADR-005 Design System Neon 360° com Light Mode como Padrão Adequação à jornada executiva de trabalho diurno mantendo chaveador rápido para Dark Mode e WCAG 2.2 AA. APROVADO / IMPL Contraste impecável, títulos sem preto/branco.
ADR-006 Estratégia de Filas Assíncronas para Integrações Externas (BullMQ/Redis) Processamento resiliente de Webhooks Bitrix24 e envios em massa sem degradar API transacional. PROPOSTO (F03) Requer ativação do Redis do novo compose.
