2. Protocolo para Revalidação Futura (Autorização Separada)

Quando autorizado formalmente o início do ciclo de revalidação técnica:

  1. Executar verificação de build do frontend: npm run build em 03_PLATAFORMA/frontend.
  2. Executar compilação do backend: npx tsc --noEmit em 03_PLATAFORMA/backend.
  3. Executar a suíte de integração Vitest: npx vitest run.
  4. Executar o script automatizado E2E HTTP: node tests/e2e-fase02.js.
  5. Registrar eventuais divergências na Matriz de Aderência sem modificar a arquitetura base.
