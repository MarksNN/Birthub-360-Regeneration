# Birthub 360° — Regeneration

Plataforma oficial de Revenue Intelligence, Orquestração Comercial e Ecossistema Supervisor + 394 Agentes Especializados.

## Estrutura do Monorepo

- `04_DOCUMENTACAO_MESTRA/`: Product Blueprint, Brandbook Neon 360°, PRD, Arquitetura C4, ADRs, Governança dos 394 Agentes e Handoff de Revalidação (Fase 00).
- `backend/`: API Node.js + TypeScript + Express + Prisma ORM + PostgreSQL 16 Multi-Tenant + Motor Supervisor.
- `frontend/`: SPA React 18 + Vite + TypeScript + Tailwind CSS (Identidade Neon 360°, Light Mode padrão e Dark Mode).
- `docs/html/`: Relatórios oficiais executivos em HTML5 (`FASE_00_RESULTADO.html`, `FASE_01_RESULTADO.html`, `FASE_02_RESULTADO.html`).
- `docker-compose.yml`: Infraestrutura local isolada (PostgreSQL 16 na porta `5433`).
